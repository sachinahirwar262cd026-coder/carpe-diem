# Frontend Module

This directory is reserved for the client-side user interface (e.g. React, Next.js, Vue, or mobile app).

### Connecting to the Models / Air Quality API:
- **Base URL:** `http://localhost:8000`
- **Forecast Endpoint:** `POST /api/forecast`
- **Cities List:** `GET /api/cities`
- **Interactive Swagger Docs:** `http://localhost:8000/docs`
